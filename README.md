# 彭建松 · 设计作品集

电商设计、活动视觉、画册与品牌应用、海报、动画及 3D 产品可视化作品。网站代码开源，作品素材保留权利。

## 内容

- Dior 六屏电商详情页与八页产品画册
- 可口可乐活动视觉与品牌应用
- 美妆、香氛、饮品海报及工作室宣传
- 《山海异兽志》获奖展板
- CHANEL N°5 3D 产品建模、材质灯光与渲染（含 Blender / GLB 下载）
- 三部个人全流程动画：二次元样片、《不周山》《丧尸认狗》

## 本地查看

直接打开 index.html 即可浏览。也可以在本目录运行 `python -m http.server 8000`，然后访问 http://localhost:8000 。无需 npm、数据库、API Key、登录或外部字体/CDN，图像和视频均使用仓库内的相对路径。

## 发布

这是可移植的纯静态网站。网站入口为根目录 index.html，静态资源目录为 assets，原始作品在 originals。

GitHub Pages：在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main、目录 / (root)，保存并等待发布。

其他静态托管：将本目录的文件按原结构上传至静态站点根目录，首页设为 index.html。无需构建命令。若平台要求输出目录，使用仓库根目录 `.`。

### 国内访问

开源仓库与网站托管是两件事。使用 GitHub Pages 或其他境外服务不能承诺国内所有地区、运营商和浏览器都稳定访问。若采用腾讯云 COS 等国内托管方案，需要按服务商要求准备自有域名、备案和 HTTPS。域名或服务费用由账号持有人确认后开通。

本仓库没有依赖 chatgpt.site、GitHub Raw 或第三方 CDN 来加载作品；可以把同一份文件直接部署到国内服务。
